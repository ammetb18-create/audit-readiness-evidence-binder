# Evidence Request Tracker

## Purpose

This evidence request tracker organizes the documentation needed to support cybersecurity audit readiness and compliance review activities.

From a GRC analyst perspective, an evidence tracker helps coordinate requests, assign ownership, monitor completion status, identify missing documentation, and support audit or customer security review responses.

## Evidence Status Definitions

| Status | Meaning |
|---|---|
| Requested | Evidence has been requested from the control owner but has not yet been reviewed. |
| Received | Evidence has been received and is ready for review. |
| Missing | Evidence has not been provided or is unavailable. |
| Needs Update | Evidence exists but is outdated, incomplete, or requires correction. |
| Gap Identified | A missing process or documentation gap has been identified. |
| Complete | Evidence has been reviewed and appears sufficient for the audit readiness purpose. |

## Priority Evidence Gaps

The highest-priority evidence gaps identified in this tracker are:

1. Quarterly access review evidence  
2. MFA enforcement evidence  
3. Critical vendor due diligence evidence  
4. Incident response tabletop testing evidence  
5. Centralized audit evidence management process  
6. Remediation tracking documentation  

## GRC Analyst Takeaway

This evidence request tracker demonstrates how a GRC analyst organizes audit evidence requests and tracks documentation readiness.

The tracker supports:

- Audit preparation
- Control owner accountability
- Evidence collection
- Gap identification
- Remediation planning
- Compliance communication
- Executive reporting

Evidence tracking is important because even if controls exist, the organization must be able to prove those controls are documented, reviewed, and operating effectively.
